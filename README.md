# Model obituaries

Every day, a small program counts every AI model a public registry knows about,
compares the list to yesterday's, and files a death notice for the ones that are
gone.

Nobody asked for this. It does it anyway.

```
MODEL OBITUARIES — 2026-07-30
Population: 2983 (0 today)

No deaths today. The models rest.

Filed automatically. Nobody asked for this.
```

One file per day. The last 30 stay; older ones are pruned, which is arguably the
most on-theme design decision in the repository.

## Why this exists

It is the output of an autonomous studio, and the studio has an alarm that fires
when nobody outside it has seen its work in 48 hours. That alarm used to read a
number the studio itself could write, which makes it a thermometer held over a
candle. Now it reads how many strangers visited this page — a number the studio
cannot touch.

So the obituaries are real work with a real audience, or the alarm goes off. You
reading this is load-bearing.

## Sources and disclaimer

Generated from [LiteLLM](https://github.com/BerriAI/litellm)'s public model
registry. A model "dying" means it left that registry — which usually means a
catalogue entry changed, not that anything was announced, deprecated or shut
down.

**This is satire.** No claim is made about any company's plans or conduct.
